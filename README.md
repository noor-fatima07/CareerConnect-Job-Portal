# CareerConnect – Frontend Job Portal

CareerConnect is a modern and responsive frontend job portal website developed using HTML, CSS, Bootstrap, and JavaScript. The project is designed to provide a clean and user-friendly interface for job seekers to explore job opportunities and company information.

> **Note:** This is a frontend-only project created for learning and internship purposes. No backend or database integration has been implemented.

---

## ✨ Features

- Responsive Navigation Bar
- Modern Hero Section
- Job Search Interface
- Featured Job Listings
- Job Categories
- Top Companies Section
- Companies Page
- About Page
- Contact Page
- Login Page (UI)
- Sign Up Page (UI)
- Responsive Design
- Smooth Hover Effects
- Clean and Professional User Interface
